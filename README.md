# சுதந்திர தமிழ் இலக்கிய மின்நூலகம் (Sutantra Tamil Literature Digital Library)

> **2,500 ஆண்டுகாலத் தமிழ் இலக்கிய வரலாற்றுப் பொக்கிஷம் — 1,143 செவ்விலக்கிய மற்றும் நவீன நூல்கள் ஒரே இடத்தில்!**

சுதந்திர தமிழ் இலக்கிய மின்நூலகம் (Sutantra) என்பது சங்க காலம் தொட்டு நவீன காலம் வரையிலான தமிழ் இலக்கியச் செல்வங்களை எண்ம வடிவில் (Digital Text Format) முறைப்படுத்திப் பாதுகாத்து வழங்கும் முழுமையான திறவூற்றுத் திட்டமாகும்.

## 🔍 தேடுதல் மற்றும் பயன்பாட்டு வழிகாட்டி

### 1. குறிப்பிட்ட நூலைத் தேட:
- கணினியில் `find` அல்லது `grep` கட்டளைகளைப் பயன்படுத்தலாம்:
  ```bash
  # திருக்குறள் கோப்பைக் கண்டறிய:
  find thamizh_noolkal -name "*thirukkural*.txt"

  # குறிப்பிட்ட சொல்லை நூல்களில் தேட:
  grep -rn "யாதும் ஊரே" thamizh_noolkal/
  ```
