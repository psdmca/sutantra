# சுதந்திர தமிழ் நூல்கள் களஞ்சியம் (Sutantra Tamil Library)

தமிழ் இலக்கியச் செல்வங்களை எண்ம வடிவில் (Digital format) பாதுகாத்து அடுத்த தலைமுறைக்குக் கொண்டு சேர்க்கும் நோக்கில் தொகுக்கப்பட்ட ஒரு முழுமையான தமிழ் நூலகக் களஞ்சியம்.

இத்தொகுப்பில் மரபுவழி இலக்கணம், அறநெறி, செவ்வியல் சங்க இலக்கியம் தொட்டு இருபதாம் நூற்றாண்டு வரையிலான **1212 தமிழ் நூல்கள்** மரபுவழிக் கற்றல் ஒழுங்குமுறைப்படி (Classical Scholar Reading Order) 12 முதன்மைத் துறைகளின் கீழ் வகைப்படுத்தப்பட்டு ஒழுங்குபடுத்தப்பட்டுள்ளன.

## 🎯 களஞ்சிய அமைப்பின் சிறப்பம்சங்கள்:
1. **மரபுவழிக் கற்றல் வரிசை (Classical Scholar Order)**: மொழி இலக்கணம் மற்றும் வாழ்வியல் அறநெறியைத் தொடக்கமாகக் கொண்டு, சங்க இலக்கியம், காப்பியங்கள், பக்தி, சித்தர், பிரபந்தங்கள் வழியாக நவீன இலக்கியம் வரை செல்லும் இயல்பான கல்விமுறை ஒழுங்கு.
2. **முழுமையான திருமுறைகள்**: தேவாரம், திருவாசகம், திருவிசைப்பா, திருமுறைக்கண்ட புராணம் மற்றும் 12-ஆம் திருமுறையான பெரியபுராணம் அடங்கிய முழுமையான பன்னிரு திருமுறைகள்.
3. **பிரபந்த வகைப்பாடு**: பிள்ளைத்தமிழ், தூது, மடல், உலா, பரணி, கலம்பகம், கோவை, பள்ளu, குறவஞ்சி, சதகம், வெண்பா, ஊசல், தாலாட்டு உள்ளிட்ட 26 தனித்தூய வகைப்பாடுகளில் 414 சிற்றிலக்கியங்கள்.
4. **மூல நூல்களும் உரைகளும்**: மூல நூல்களுடன் உரையாசிரியர்களின் செவ்வியல் உரைகளும் தனியாகத் தொகுக்கப்பட்டுள்ளன.
5. **அனைத்து இணைப்புகளும் சரிபார்க்கப்பட்டவை**: அனைத்து அடைவுகளிலும் README வழிகாட்டிகளும் துல்லியமான உள்ளிணைப்புகளும் 100% பராமரிக்கப்படுகின்றன.
