# சுதந்திர தமிழ் இலக்கிய மின்நூலகம் (Sutantra Tamil Literature Library)

> **2,500 ஆண்டுகாலத் தமிழ் இலக்கிய வரலாற்றுப் பொக்கிஷம் — 1,311 செவ்விலக்கியக் கோப்புகள் ஒரே இடத்தில்!**

சுதந்திர தமிழ் இலக்கிய மின்நூலகம் என்பது சங்க காலம் தொட்டு நவீன காலம் வரையிலான தமிழ் இலக்கியச் செல்வங்களை எண்ம வடிவில் (Digital Text Format) முறைப்படுத்திப் பாதுகாத்து வழங்கும் முழுமையான திறவூற்றுத் திட்டமாகும்.

## 🔍 தேடுதல் மற்றும் பயன்பாட்டு வழிகாட்டி

### 1. குறிப்பிட்ட நூலைத் தேட:
- கணினியில் `grep` அல்லது கோப்புத் தேடலைப் பயன்படுத்தலாம்:
  ```bash
  # திருக்குறள் கோப்பைக் கண்டறிய:
  find texts -name "*திருக்குறள்*.txt"

  # குறிப்பிட்ட சொல்லை நூல்களில் தேட:
  grep -rn "யாதும் ஊரே" texts/
  ```

### 2. மெட்டாடேட்டா விபரங்கள்:
அனைத்து 1,385 கோப்புகளின் முழுமையான மெட்டாடேட்டா அட்டவணை [`texts/நூற்பட்டியல்_mapping.json`](texts/நூற்பட்டியல்_mapping.json) கோப்பில் JSON வடிவில் உள்ளது.
