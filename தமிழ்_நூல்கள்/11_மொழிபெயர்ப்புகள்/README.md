# 11. உலக இலக்கிய மொழிபெயர்ப்புகள் (World Literature & Translations)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Directory)](../README.md)

*விவிலியம் (பழைய & புதிய ஏற்பாடுகள்), உலகப் பொதுமறைகள், காப்பியங்கள், செவ்விலக்கியங்கள் மற்றும் நவீன இலக்கியங்களின் தமிழ் மற்றும் ஆங்கில மொழிபெயர்ப்புக் களஞ்சியம்.*
