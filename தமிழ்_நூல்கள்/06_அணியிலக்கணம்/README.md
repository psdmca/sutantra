# 06. அணியிலக்கணம்

இந்தக் கோப்பகத்தில் `books.txt` நூல் பட்டியலின்படி **06. அணியிலக்கணம்** பிரிவைச் சார்ந்த முதன்மை நூல்கள் வகைப்படுத்தப்பட்டுள்ளன.

## `books.txt` பட்டியல் மற்றும் சேகரிப்பு நிலை

| குறியீடு (Code) | நூல் பெயர் (Book Title) | நிலை (Status) |
|:---:|:---|:---:|
| AN-001 | தண்டியலங்காரம் | ⏳ Not Collected |
| AN-002 | மாறனலங்காரம் | ⏳ Not Collected |
| AN-003 | அலங்கார நூல்கள் மற்றும் உரைகள் | ⏳ Not Collected |

> [!NOTE]
> இப்பிரிவைச் சார்ந்த நூல்கள் தற்போது மூலக் களஞ்சியத்தில் (`texts/`) சேகரிக்கப்படவில்லை (`[ ] Not Collected`). எதிர்காலத்தில் சேர்க்கப்படும் போது இங்கு நகலெடுக்கப்படும்.
