# 3. அற இலக்கியம் மற்றும் நீதிநூல்கள் (Didactic & Moral Literature)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Directory)](../README.md)

*மனித வாழ்வின் விழுமியங்கள், ஒழுக்கம், அறநெறி மற்றும் வாழ்வியல் கோட்பாடுகளை விளக்கும் சங்க மருவிய கால மற்றும் பிற்கால நீதிநூல்கள்.*
