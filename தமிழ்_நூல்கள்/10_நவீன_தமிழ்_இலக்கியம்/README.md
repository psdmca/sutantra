# 10. நவீன தமிழ் இலக்கியம் (Modern Tamil Literature)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Directory)](../README.md)

*நவீனத் தமிழ் நாவல்கள், சிறுகதைகள், புதுக்கவிதைகள், நாடகங்கள் மற்றும் தமிழறிஞர்களின் ஆய்வுக் கட்டுரைகள்.*
