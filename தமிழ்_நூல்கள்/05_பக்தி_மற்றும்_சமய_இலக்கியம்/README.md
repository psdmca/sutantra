# 5. பக்தி மற்றும் சமய இலக்கியம் (Devotional & Religious Literature)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Directory)](../README.md)

*பன்னிரு திருமுறைகள், சைவ சித்தாந்த சாத்திரங்கள், திருவருட்பா, முருகன் இலக்கியம், நாலாயிரத் திவ்வியப் பிரபந்தம், மற்றும் பௌத்த/சமண இலக்கியங்கள்.*
