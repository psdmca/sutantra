`books.txt` நூல் பட்டியலின் 19 செவ்வியல் வகைப்பாட்டுப் பிரிவுகளின்படி ஒழுங்கமைக்கப்பட்ட முதன்மைத் தமிழ் நூல்களின் தொகுப்பு.

> **குறிப்பு**: இத்தொகுப்பில் `books.txt`-இல் வகைப்படுத்தப்பட்ட முதன்மை நூல்கள் மட்டுமே நகலெடுத்து வகைப்படுத்தப்பட்டுள்ளன. களஞ்சியத்தின் முழுமையான மூலக்கோப்புகள் `texts/` கோப்பகத்தில் அப்படியே பாதுகாக்கப்பட்டுள்ளன.
