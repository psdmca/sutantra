# 8. வரலாறு, வாழ்க்கை வரலாறு மற்றும் சுவடிகள் (History & Biography)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Texts Index)](../README.md)

*தமிழ்த் தாத்தா உ.வே.சா அவர்களின் 'என் சரித்திரம்', வ.உ.சிதம்பரனார் வரலாறு, தமிழக வரலாற்று ஆய்வுகள், மற்றும் கல்வெட்டு மெய்க்கீர்த்திகள்.*

### 'என் பார்வையில் கலைஞர்' (இரண்டு பாகங்களாக)

- **ஆசிரியர்**: சு. சமுத்திரம்‌
- **வகைப்பாடு**: வாழ்க்கை வரலாறு
- **காலம் / மரபு**: மரபுவழி தமிழ் இலக்கியம்
- **நூல் விளக்கம்**: இந்நூல் 'வாழ்க்கை வரலாறு' என்னும் பிரிவின் கீழ் அமைந்துள்ள சிறப்புமிக்க தமிழ் இலக்கியப் படைப்பாகும். இத்தொகுப்பில் இந்நூலின் 2 கோப்புகள் மூலமும் உரைகளுமாகத் தொகுக்கப்பட்டுள்ளன.
