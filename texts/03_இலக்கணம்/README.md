# 3. இலக்கண நூல்கள் (Tamil Grammatical Treatises)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Texts Index)](../README.md)

*தொல்காப்பியம், நன்னூல், யாப்பருங்கலக் காரிகை, செய்யுளிலக்கணம், தண்டியலங்காரம், நவநீதப் பாட்டியல் உள்ளிட்ட தமிழின் எழுத்து, சொல், பொருள், யாப்பு, அணி இலக்கணப் பொக்கிஷங்கள்.*

> **குறிப்பு**: இப்பிரிவில் இருந்த 15 இலக்கண நூல்களும் செவ்வியல் முறைப்படி தூய்மைப்படுத்தப்பட்டு `தமிழ்_நூல்கள்/` (04_இலக்கண_நூல்கள், 05_யாப்பு_மற்றும்_பாட்டியல், 06_அணியிலக்கணம், 07_நிகண்டுகள்) கோப்பகங்களுக்கு நகர்த்தப்பட்டுள்ளன.

**மொத்தக் கோப்புகள்**: 0 கோப்புகள் (அனைத்தும் `தமிழ்_நூல்கள்/`-க்கு நகர்த்தப்பட்டன)
