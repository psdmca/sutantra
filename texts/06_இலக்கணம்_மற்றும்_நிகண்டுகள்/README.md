# 6. இலக்கணம் மற்றும் நிகண்டுகள் (Grammar & Lexicons)

> [🔙 முதன்மைப் பொருளடக்கம் (Main Texts Index)](../README.md)

*தமிழின் தொன்மை வாய்ந்த முழுமையான இலக்கண நூலான தொல்காப்பியம், நன்னூல், யாப்பிலக்கணம், அணியிலக்கணம் மற்றும் சொல்லகராதிகளான நிகண்டுகள்.*
