# சுதந்திர தமிழ் இலக்கிய மின்நூலகப் பொருளடக்கம் (Texts Master Index)

> **சுதந்திர தமிழ் நூலகம் (Sutantra Tamil Literature Digital Library)**
> 2,500 ஆண்டுகாலத் தமிழ் இலக்கியப் பாரம்பரியத்தின் **1,143 செவ்விலக்கியக் கோப்புகள்** அனைத்தும் செம்மைப்படுத்தப்பட்டு முழுமையாக [`தமிழ்_நூல்கள்/`](../தமிழ்_நூல்கள்/README.md) அடைவிற்குள் 11 முதன்மைப் பெரும் பிரிவுகளாக மறுசீரமைக்கப்பட்டு நகர்த்தப்பட்டுவிட்டன.
